# Direction - Cadence

This page is the horizon. It sits apart from the state page, which says where the last session stopped and is rewritten at every close. This page moves only when the horizon does, and only with the owner.

## End state

Mara can read any card, newsletter or web page the studio puts out and find nothing she would change for a reason already in the ledger. A new wording problem is a new problem, never an old one coming back.

## Done test

Over one full quarter the corrections ledger gains no entry that repeats an earlier one, and Mara says so in so many words at the review.

## Horizon

Review by 2031-05-01. If the quarter is not clean by then, Mara and Cadence look first at whether the style sheet is too long to be read, before adding another tool.

## What would move it

- Mara starts a new kind of writing the style sheet does not cover (talks, say, or a catalogue).
- Mara wants Cadence to look after something new. That is a change to the charter first, and only the owner changes the charter.
